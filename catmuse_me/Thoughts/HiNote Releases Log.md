## 0.2.12

**v0.2.12 - 2025-02-12**

1. 新增任意格式文本提取设置，需自定义正则表达式；
2. 新增高亮卡片标签功能，批注输入框输入格式： `#标签1 #标签2`
3. 新增主视图下拖拽到文件功能，可以文档之间建立链接；
4. 新增主视图下标题悬停预览；

**v0.2.12 - 2025-02-12**

1. Added settings for extracting text in any format, requiring custom regular expressions;
2. Added a feature for highlighting card tags, with the annotation input box format: `#tag1 #tag2`
3. Added a drag-to-file feature in the main view, allowing the creation of links between documents.
4. Added title hover preview under the main view.

## 0.2.8

- Exporting as a new note can create links based on BlockID.
